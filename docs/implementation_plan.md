# 手动实施规划与参数记录

建议先阅读 [技术路线](technical_route.md)，再按下面的阶段操作。本文件只描述实施顺序和检查项，不固定过滤、训练或统计参数，也不提供自动执行脚本。

## 1. 阶段安排

| 阶段 | 手动操作 | 预计软件 | 交付物 | 进入下一阶段前检查 |
|---|---|---|---|---|
| 数据与环境 | 阅读来源；建立样本/患者关系；选择 R 或 Python 主线；建立环境 | R/RStudio 或 Python/Jupyter | 数据清单、版本、样本映射 | counts 含义、文件与样本独立性明确 |
| 单细胞质控 | 逐样本查看 QC，处理低质量和双细胞候选 | Seurat＋可选 scDblFinder；或 Scanpy | 原始对象、QC 后对象、过滤记录 | 阈值有依据，重要细胞群未被机械删除 |
| 注释与参考 | 聚类、marker 复核；建立标签层级；划分训练与保留供者 | Seurat；需要时加入整合工具 | 带标签参考、marker 表、供者分布、映射 | CAF/CD8 与相近群体可区分，细分类有供者支持 |
| 空间与边界 | 对齐 counts/坐标/H&E，复核分区，确定边界和排除规则 | Seurat＋QuPath | 空间对象、区域标签、边界图、纳入表 | 分区独立于目标预测，坐标与单位正确 |
| 方法质量 | 先运行一种方法；供者隔离测试；检查稀有类型与简单对照 | RCTD；NNLS 辅助 | 预测、诊断、分类型误差、参数 | 目标细胞识别能够支持下游分析 |
| 开发队列分析 | 固定主要指标，逐患者估计效应，检查组成与空间结构 | R 空间与统计工具；可选 Squidpy | 患者效应、敏感性分析、图 | 患者数、可用边界和不确定性支持相应表述 |
| 参考与粒度比较 | 引入独立参考，分别改变标签粒度，再加入第二种方法 | Seurat/Scanpy、RCTD、cell2location | 条件清单、对照结果、稳定性图 | 共同标签、样本和指标一致 |
| 独立空间复现 | 外部纳入和基因映射；按固定规则分析；汇总患者 | 与开发阶段一致的主要工具 | 外部效应、异质性、复现判定 | 队列独立，平台和分区差异得到处理 |
| 深挖与整理 | 解释稳定结果；完成图组、README 与复现记录 | 富集/表达评分及绘图工具 | 可公开的科研展示项目 | 主张能指向实际结果、来源和运行记录 |

方法质量不足时，先检查基因、标签、参考、输入尺度和模型设置。边界或患者不足时，优先完善数据与分区，不通过改变阈值追求某个结果。

## 2. 操作节奏

1. **先做最小可检查流程。** 一个参考、一张资料完整的空间切片，验证读入、标签、坐标和模型输出。起步样本不能代替最终队列。
2. **再完成单一方案的开发队列。** 人工查看所有样本的 QC、分区与关键细胞分布。
3. **再扩展比较维度。** 优先一次改变参考、粒度或方法中的一项，保留改变的原因。
4. **最后独立验证和机制解释。** 调过参数的数据用于开发诊断；独立验证使用另外固定的样本或队列。

## 4. 每次运行保留哪些记录

- 输入来源与对象版本，使用的样本/供者清单。
- 软件版本、完整参数、随机种子和本次改变的原因。
- 过滤前后数量、模型诊断、异常与排除理由。
- 输出对象、结果表、成图数据和图注。

R 可记录 `sessionInfo()`，Python 可记录环境包版本。环境选定后再决定是否用 renv、uv 等锁定依赖，不需要一开始搭建复杂调度系统。

## 5. 后续目录按阶段建立

原始数据目录保持只读习惯。开始手动分析后，可以建立 `analysis/` 存放你编写或确认的分析文件、`data/processed/` 存放转换对象、`results/` 存放结果。本次没有预建分析脚本或运行配置。

分别保存各阶段对象，不覆盖原始文件；给分析方案清楚命名，避免不同参数结果互相覆盖。公开 GitHub 时保留代码、参数、适量结果和数据入口，大型原始矩阵不直接提交。
